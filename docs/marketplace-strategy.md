# 📢 استراتيجية "السوق المُعلن" — نموذج أوليكس / جوميا / تيمو

**التاريخ:** أغسطس 2026
**المشروع:** منصة ماذا (maza.online)
**الهدف:** تحويل الموقع إلى منصة "إعلانات ديناميكية" بجذب الزوار عبر محتوى يبحثون عنه، وإجبارهم على تسجيل مجاني لفتح التفاصيل، وبناء قاعدة بيانات متنامية.

---

## 1) الفكرة في سطر واحد

> **الزائر يبحث عن حاجة (وظيفة / سفر / اختبار مجاني / خدمات أسر) → يلاقي إعلان مربوط بيها → يدوس → يلاقي التفاصيل ناقصة → "سجّل مجانًا لترى باقي التفاصيل" → يسجل → يفتح له المحتوى → صار رقمه/إيميله ضمن قاعدة بياناتنا.**

المنتج الحقيقي ليس الإعلان — المنتج الحقيقي هو **قاعدة بيانات المتصفحين والمتقدمين**.

---

## 2) سلوك الزائر (حلقة التحويل)

```
بحث على جوجل / سوشيال ميديا
        ↓
نتيجة: إعلان/قائمة على منصة ماذا
        ↓
يدخل على الموقع (Landing)
        ↓
يرى التشويق: العنوان + الصورة + ملخص مثير
        ↓
يحاول يرى رقم التواصل / التفاصيل الكاملة
        ↓
⚠️ يظهر حاجز: "سجّل مجانًا لتستطيع رؤية التفاصيل"
        ↓
يسجل (بريد / رقم موبايل)
        ↓
يُفتح المحتوى الكامل + يتحول لـ "عميل محتمل" في قاعدة البيانات
```

**مبادئ أساسية:**
- المحتوى يجب أن يكون **حقيقيًا ومفيدًا** — أي إحساس بالخداع يقتل الموقع.
- التسجيل **مجاني 100%** — الحاجز ليس مالًا، بل بيانات.
- الرحلة يجب أن تكون **سريعة** (< 30 ثانية للتسجيل) وإلا يهرب الزائر.

## 3) "الطُعم" (The Bait) — المحتوى الذي يجذب الزوار

| الفئة | أمثلة | حجم الطلب في مصر | حالتها في المشروع |
|---|---|---|---|
| **وظائف** | وظائف أخصائيين، مراكز، عمل عن بُعد | 🔥 عالي جدًا | موجود (JobApplication) |
| **اختبارات مجانية** | اختبار ذكاء/شخصية/ميول + نتيجة + كوبون خصم | 🔥 عالي جدًا | موجود (Quiz) |
| **أسر وخدمات** | المراكز والأخصائيين يعلنون عن أنفسهم | 🟡 متوسط | موجود (AdvertiseLead) |
| **سفر ومنح** | منح دراسية، تأشيرات، عروض سفر | 🔥 عالي (مطلوب مستقبلًا) | غير موجود |
| **دورات مجانية** | ورش، كورسات مجانية | 🟡 متوسط | غير موجود |

**القاعدة الذهبية:** ابدأ بالفئات الموجودة فعلًا، ووسّع تدريجيًا.

## 4) مصدر المحتوى (من أين يجيء "الطُعم"؟)

| الطريقة | الوصف | المميزات | العيوب |
|---|---|---|---|
| **محتوى ذاتي** | ننشر إعلانات بأنفسنا | مضمون وموثوق | بطيء |
| **محتوى مستخدمين (Marketplace)** | أي حد يعلن (نموذج أوليكس) | قوي جدًا + مجاني | يحتاج بداية وثقة |
| **سكراب مصادر عامة** | وظائف حكومية، منح معلنة | سريع | ⚠️ مخاطر قانونية |

**التوصية:** ابدأ بـ "محتوى مستخدمين" + "ذاتي" معًا.

## 5) نظام الحاجز (The Login Wall / Registration Wall)

هو **قلب الفكرة** — لا محتوى كامل بدون تسجيل.

```
🔓 الحالة العامة (للزائر المجهول):
   العنوان + الصورة + ملخص 1-2 سطر + عدد المتقدمين
   [🔒 سجّل مجانًا لترى رقم التواصل / التفاصيل الكاملة]

✅ الحالة بعد التسجيل:
   رقم التواصل (واتساب) + التفاصيل الكاملة + أزرار (واتساب / اتصال / موقع)
```

**أين يُطبق الحاجز:**
1. صفحة تفاصيل إعلان (مركز / أخصائي)
2. صفحة تفاصيل وظيفة (رقم صاحب الوظيفة)
3. نتيجة الاختبار التفصيلية (بعد الإجابة → تسجيل → تظهر النتيجة + الكوبون)

**ماذا نجمع عند التسجيل:**
- الإيميل أو رقم الموبايل (إجباري)
- الاسم (اختياري في البداية لتقليل الاحتكاك)
- المدينة (اختياري)

## 6) نموذج الربح (Monetization)

| الطريقة | الوصف | التنفيذ على ماذا |
|---|---|---|
| **إعلان مميز (Featured)** | الإعلان يظهر أعلى النتائج | إضافة حقل `featured` في السكيمة + أيقونة "مميز" |
| **Boost** | دفع مقابل ظهور أعلى / مدة أطول | نظام طلبات داخل لوحة الأدمن |
| **عمولة** | نسبة من الصفقة المكتملة | لاحقًا |
| **بيع قاعدة البيانات (B2B)** | تزويد الشركات بقوائم المتقدمين | لاحقًا (بموافقة المستخدمين) |
| **كوبونات خصم** | شراء الجلسات/التقييمات | ✅ موجود (Coupon + Quiz) |

## 7) الـ SEO — زوار مجانيون مستمرون

- كل إعلان = **صفحة مستقلة بعنوان مفيد**:
  - `maza.online/directory/center/مركز-التطور-القاهرة`
  - `maza.online/jobs/وظيفة-اخصائي-تخاطب-الجيزة`
- كل فئة = صفحة قائمة (Index) + صفحات فرعية حسب المحافظة.
- إضافة سكيما البيانات المنظمة (Schema.org `JobPosting` / `LocalBusiness`) لظهور غني في جوجل.

- ✅ منع السبام والوهم — سياسة واضحة

## ⚠️ 9) الحدود القانونية والأخلاقية (مهم جدًا)

| مسموح ✅ | غير مسموح ❌ |
|---|---|
| إخفاء التفاصيل الكاملة خلف تسجيل مجاني | إعلانات كاذبة / وهمية |
| جمع بيانات المتصفحين برضاهم | بيع البيانات دون موافقة |
| سكراب من مصادر مرخصة | سكراب بيانات شخصية محمية |
| حاجز تسجيل (وليس دفع) لعرض المعلومات | جعل الخدمة الأساسية مدفوعة إجباريًا |

> النموذج الشرعي = "محتوى حقيقي + تسجيل مجاني للعرض الكامل" — وهذا ما تفعله بوابات الوظائف وأوليكس.

# 🚀 خطة التنفيذ على موقع ماذا — (5 مراحل)

## المرحلة 1: أساسيات العرض والدليل (الأهم فورًا)

### 1.1 إنشاء "دليل المراكز والأخصائيين" (Directory)
- **سكيمة جديدة** `DirectoryListing` (أو استغلال `AdvertiseLead` بعد قبول الإعلان):
  - `name`, `type` (center/specialist), `city`, `phone`, `description`, `services[]`, `featured (bool)`, `approved (bool)`, `views (count)`
- **صفحة قائمة** `/directory` — عرض بطاقات الأعلانات المقبولة.
- **صفحة تفاصيل** `/directory/[slug]` — هنا يُطبَّق **الحاجز**:
  - زائر مجهول: العنوان + الصورة + ملخص + عدد المشاهدات + `🔒 سجّل مجانًا لرؤية رقم التواصل`
  - مستخدم مسجل: كل التفاصيل + رقم واتساب + زر اتصال
- **لوحة أدمن**: قبول/رفض الإعلانات + تمييز + حذف.

### 1.2 تحويل الوظائف إلى نموذج متبادل (Two-sided)
- حالياً `JobApplication` = المتقدم يرسل سيرته الذاتية.
- **المطلوب**: إضافة `JobListing` (إعلان وظيفة من مركز/شركة) يحتوي رقم تواصل، ثم:
  - القائمة `/jobs` تعرض الإعلانات.
  - التفاصيل محجوبة خلف التسجيل.
  - المتقدم يسجل + يرفع السيرة (تحصل على بياناته).

### 1.3 الاختبار (Quiz) — تغذية مباشرة لقاعدة البيانات
- النتيجة التفصيلية + الكوبون **لا تظهر إلا بعد تسجيل الدخول**.
- هكذا كل "اختبار مجاني" = بيانات زائر جديدة.

## المرحلة 2: نظام التسجيل "السريع" (Quick Auth)
- حاليًا يوجد `lib/auth.ts` (NextAuth) لكن التسجيل طويل (اسم + إيميل + باسورد + تفعيل).
- **المطلوب**: "تسجيل سريع" بخطوة واحدة:
  - إما رقم موبايل + كود OTP عبر SMS/WhatsApp، أو
  - تسجيل جوجل/فيسبوك بضغطة (أولوية!)
- الهدف: التحويل من "سجّل" لـ "أنا عضو" بأقل احتكاك.

## المرحلة 3: نظام الإعلانات المميزة والتحقق
- حقل `featured` + شارة "⭐ مميز".
- طلب دفع عبر Stripe (موجود) لتمييز إعلان.
- تأكيد رقم صاحب الإعلان قبل النشر.

## المرحلة 4: صفحات ديناميكية صديقة لـ SEO
- صفحات قائمة لكل فئة × محافظة.
- سكيما `JobPosting` و `LocalBusiness`.
- كل إعلان بمعرّف نصي (slug) عربي/إنجليزي.

## المرحلة 5: نمو (فئات جديدة)
- سفر ومنح دراسية.
- دورات وورش مجانية.
- إعلانات عامة (سيارات، عقارات — كمرحلة لاحقة بعيدة).

## ✅ ما تم تنفيذه (17 أغسطس 2026) — بطريقة جراحية (إضافة فقط)

### جدول جديد
```prisma
model DirectoryListing {
  id          String   @id @default(uuid())
  slug        String   @unique
  name        String
  type        String   @default("center") // center | specialist
  phone       String
  city        String
  description String?  @db.Text
  services    String?  @db.Text // JSON array
  image       String?
  featured    Boolean  @default(false)
  approved    Boolean  @default(false) // نشر فقط بعد الموافقة
  views       Int      @default(0)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}
```

### الملفات المضافة
| الملف | الوظيفة |
|---|---|
| `app/api/directory/route.ts` | قائمة الإعلانات المقبولة (عام) |
| `app/api/directory/[slug]/route.ts` | التفاصيل + **الحاجز**: `phone` مخفي للزوار غير المسجلين |
| `app/api/admin/directory/route.ts` | إدارة كاملة (إنشاء/تعديل/قبول/رفض/تمييز/حذف — أدمن) |
| `app/directory/page.tsx` | قائمة البطاقات (فلترة + مميز) |
| `app/directory/[slug]/page.tsx` | صفحة التفاصيل — حاجز `🔒 سجّل مجانًا لرؤية رقم التواصل` |
| `app/dashboard/admin/directory/page.tsx` + `components/AdminDirectoryClient.tsx` | لوحة إدارة الدليل |
| تعديل `AdminLeadsClient.tsx` | زر "نشر في الدليل ⭐" |
| تعديل `layout.tsx` (أدمن) + `ClientNavbar.tsx` | روابط جديدة |
